1. Ask. The tenant's AI agent (or a person in tab 03) picks a dataset and a template.
  2. Sizes, not data. The console sends ChainAim's signer file sizes, ids and hashes only; the signer refuses any other field.
  3. Signed quote · counter-offer. A firm AP2 quote (ES256) with signed limits. Over the tenant's auto-approve limit, the agent asks once for a smaller job at that limit: the price is never discounted, only the job shrinks.
  4. Mandate + pay. The agent signs an AP2 checkout mandate with the tenant's key for this quote and one payment, and pays USDC on NEAR over x402 (a NEP-366 relayer pays the gas), before any work.
  5. Masked call. The exact answer is computed on the PC; one model call on masked text runs on NEAR AI (Intel TDX + NVIDIA GPU) and its attestation is verified before the result is released. Not proven: refunded on NEAR.
  6. Signed receipt. Ed25519, hashes only: price, both signatures, payment, attestation, and what left the PC.
  7. Matched. The admin console reads NEAR itself and matches each payment claim with its chain transaction.
